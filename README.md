# dpros - Local Artisan Directory Platform
Created by DXofficials (2026)

## Overview
dpros is a sleek, matte black and metallic gold web application designed to help users instantly discover, filter, and connect with verified local artisans and professionals via WhatsApp.

## Project Structure
The project consists of the following core files:
1. `data.js` - Dynamic Data Layer and LocalStorage Manager containing default artisan data and categories.
2. `style.css` - Global stylesheet built with a Matte Black & Metallic Gold aesthetic, responsive layouts, and modern container styles.
3. `index.html` - Homepage featuring the top sponsored banner space, hero search, horizontal category chips, and featured artisan grid.
4. `search.html` - Dedicated directory search and filter page.
5. `register.html` - Business registration form allowing new artisans to list their services.
6. `advertise.html` - Sponsorship and advertisement information page with WhatsApp booking integration.
7. `safety.html` - User guidelines and safety tips for hiring local professionals.

## How to Run Locally
1. Download or clone all files (`data.js`, `style.css`, `index.html`, `search.html`, `register.html`, `advertise.html`, `safety.html`) into the same folder on your computer.
2. Open `index.html` in any modern web browser (or run it via a local development server like Live Server in VS Code).
